System Architecture & Pipeline

  • Data Ingestion: 32,582 historical credit files preprocessed with ratio engineering.
  • Model Serving: FastAPI asynchronous microservice with automated SHAP factor extraction.
  • Database Logging: PostgreSQL ORM via SQLAlchemy with resilient SQLite local fallback.
  • Macroeconomic Drift: Kolmogorov-Smirnov statistical tests run across baseline vs production batches.
  • Containerization: Multi-service Docker Compose deploying DB, FastAPI API, and Frontend.

Regulatory Compliance Matrix

  • CBO Circular BM 1120: Personal loans capped at 50% Debt Burden Ratio (DBR).
  • IFRS-9 Expected Credit Loss: Probability of Default (PD) scoring within Basel III capital requirement parameters.
  • Mala'a Credit Bureau: Automated historical delinquency checks integrated into scoring.
  • Explainable AI (XAI): SHAP values provide compliant adverse-action notice explanations.
